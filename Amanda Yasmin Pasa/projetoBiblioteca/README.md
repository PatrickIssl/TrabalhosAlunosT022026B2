# Projeto Biblioteca

Sistema de biblioteca em Java (console), baseado no sistema de locadora.

## Funcionalidades
1. Listar livros (com disponibilidade)
2. Cadastrar livro
3. Excluir livro (não permite se estiver emprestado)
4. Emprestar livro (máximo de 2 livros por usuário)
5. Devolver livro
6. Registrar usuário
7. Listar usuários (com os livros emprestados)
0. Sair

## Como executar
```
cd src
javac fag/Principal.java fag/objetos/*.java
java fag.Principal
```
